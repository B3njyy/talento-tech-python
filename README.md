# Ejercicios de Python - Talento Tech

Este repositorio reúne los ejercicios que voy realizando durante el curso de Talento Tech. Se irá actualizando con nuevas clases, prácticas y trabajos a medida que avance en mi aprendizaje de Python.

## Contenido

| Clase | Archivo | Temas practicados |
| --- | --- | --- |
| 01 | `clase-01/personalizado.py` | Uso de `print()` y mensajes por consola |
| 01 | `clase-01/saludo_personalizado.py` | Entrada de texto y saludo personalizado |
| 02 | `clase-02/tarjeta_presentacion.py` | Entrada de datos, variables y salida organizada |
| 03 | `clase-03/validacion_datos.py` | Condicionales y validación de datos |
| 04 | `clase-04/condicionalesII.py` | Condicionales anidados, validación básica de correo y rangos de edad |
| 05 | `clase-05/while.py` | Bucle `while`, validación de ingresos, acumulación y promedio |

## Cómo ejecutar los ejercicios

Es necesario tener Python instalado. Desde la carpeta principal del repositorio, se puede ejecutar cada archivo con estos comandos:

```bash
python clase-01/personalizado.py
python clase-01/saludo_personalizado.py
python clase-02/tarjeta_presentacion.py
python clase-03/validacion_datos.py
python clase-04/condicionalesII.py
python clase-05/while.py
```
